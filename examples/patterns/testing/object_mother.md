# Object Mother

**Category:** Testing  
**Demo:** [object_mother.pys](object_mother.pys)  
**Wikipedia / ref:** [Object Mother](https://martinfowler.com/bliki/ObjectMother.html)

## Intent

Named factory methods that return valid fixtures.

## Prompting an AI

**Say this:** “OrderMother.paidCatan() and emptyDraft().”

**Not this:** “Copy-paste 20 field assignments in every test.”

**Confusion to avoid:** Object Mother ≠ Test Data Builder.

```text
python -m transpiler run examples/patterns/testing/object_mother.pys
```
