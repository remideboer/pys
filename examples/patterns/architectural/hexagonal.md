# Hexagonal architecture (ports and adapters)

**Category:** Architectural  
**Status: stub — implement later**

**Wikipedia:** [Hexagonal architecture (software)](https://en.wikipedia.org/wiki/Hexagonal_architecture_%28software%29)

## Intent

Keep the domain at the center; drive it through **ports** (interfaces) and plug
**adapters** (DB, HTTP, UI) at the edges.

## Why stubbed as a pattern demo

Living teaching code already exists in layered shop examples
([`examples/database/`](../../database/), [`examples/rest-api/shop/`](../../rest-api/shop/)).
A dedicated miniature hexagon demo can be added later.
