# CQRS (Command Query Responsibility Segregation)

**Category:** Messaging  
**Status: stub — implement later**

**Wikipedia:** [Command Query Responsibility Segregation](https://en.wikipedia.org/wiki/Command_Query_Responsibility_Segregation)

## Intent

Separate the model used to **change** state (commands) from the model used to
**read** it (queries), often with different stores.

## Why stubbed

Usually pairs with event sourcing and multiple databases — too heavy for a first
patterns increment.
