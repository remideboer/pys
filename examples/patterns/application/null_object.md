# Null Object

**Category:** Application  
**Demo:** [null_object.pys](null_object.pys)  
**Wikipedia / ref:** [Null Object](https://en.wikipedia.org/wiki/Null_object_pattern)

## Intent

Do-nothing implementation instead of null checks.

## Prompting an AI

**Say this:** “NullNotifier so Checkout always has a Notifier.”

**Not this:** “nullable notifier and if (n != null) everywhere.”

**Confusion to avoid:** Null Object ≠ optional/nullable type.
