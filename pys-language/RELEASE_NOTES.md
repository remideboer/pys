# PYS Language Support 0.0.93

Trunk-based extension release. Tag: `extension-v0.0.93`.

Icons: braces + two eyes (“P eyes”) in the light teal palette. Run
`python tools/local_ci.py` before tagging.

## Highlights

- **Icons:** `{ 👁👁 }` — braces + two eyes (“P eyes”); marketplace PNG uses the
  light scheme (teal `#0F766E` / mint `#ECFDF5`); mirrored braces for even
  side padding; light/dark file icons + activity-bar logo updated.
- Continues 0.0.91–0.0.92: private access in interpolations; brace indent;
  prior single-eye icon pass.

## Install

- **Marketplace** (when published): `ext install remideboer.pys-language`
- **ELO / offline:** download `pys-student-0.0.93.zip`, unzip, run `install.cmd`
  (Windows) or `./install.sh` (macOS/Linux), then reload the editor.

Requires Python 3.10+ on PATH. For JavaScript Run/Debug, also install Node.js.
The pack includes the bundled transpiler.
