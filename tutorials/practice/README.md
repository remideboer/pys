# Part-task practice

Short drills for **recurrent** skills. Time-box (5–10 minutes), then return to a whole task.

| Drill | Skill |
|-------|--------|
| [P-interpolation](P-interpolation.md) | Choose `#i` / `#f` / `#s` / `#b` under time pressure |
| [P-declarations](P-declarations.md) | `const` vs `fix` vs `var` vs typed binding |
| [P-visibility](P-visibility.md) | Pick the door policy for a name |
| [P-struct](P-struct.md) | Struct vs dict vs class; fix-bound mutate |

These are not “lessons”. If you can do them cold, skip them.
