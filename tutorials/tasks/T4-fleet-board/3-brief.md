# T4 level C — conventional brief

## Situation

The airport needs a **Loadable** contract: `load(int weight)` and `int capacity()`.
Two machines: **Cart** (capacity 50) and **Hold** (capacity 500). Loading above capacity must print `REJECT` instead of accepting.

## Deliverable

Module + small driver entry file. Driver loads a legal and an illegal weight on each machine (or clearly shows the rule).

## Done when

T4 success criteria hold; the capacity rule is visible in behavior, not only in a comment.
